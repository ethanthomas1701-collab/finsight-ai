# FinSight AI

Plateforme d'analyse financière d'entreprises cotées, construite à partir de données publiques (SEC EDGAR).

## Statut

En construction. Phase 0 : mise en place du dépôt et premier accès aux données.

## Objectif

Permettre de rechercher une entreprise par son ticker (ex. MSFT) et d'obtenir :
- son chiffre d'affaires, son résultat net et son bilan ;
- des ratios financiers calculés (marge nette, ROE, endettement) ;
- à terme, une explication des résultats par un assistant IA.

## Sources de données

- [SEC EDGAR](https://www.sec.gov/edgar/sec-api-documentation) : rapports officiels des entreprises américaines.
